# Campus Judge 项目当前基线

最后核对日期：2026-10-07

本文档记录当前项目的实际状态，作为后续迭代的比较基准。内容区分代码事实、已执行测试和未验证事项，不将设计方案中的计划自动视为已实现功能。

## 1. 项目定位

项目面向课程实训和毕业实习演示，目标是提供轻量、可运行、易部署的在线编程机考系统。当前版本只进行 Java 字符串匹配模拟判题，不编译或执行用户代码。

## 2. 技术和运行基线

| 项目 | 当前约定 |
| --- | --- |
| 前端 | Vue 3、Vite、Axios、原生表单和 CSS |
| 后端 | Java 8、Spring Boot 2.7.18、MyBatis-Plus 3.5.5 |
| 数据库 | MySQL 8；测试使用 H2 和本机 MySQL 联调 |
| 前端开发 | `frontend`目录执行`npm.cmd ci`、`npm.cmd run dev` |
| 后端开发 | `backend`目录执行`mvn spring-boot:run` |
| 前端构建 | `npm.cmd run build` |
| 后端构建 | `mvn package` |
| 默认前端地址 | `http://localhost:5173` |
| 默认后端地址 | `http://localhost:8080` |
| 时间规则 | 设计上使用北京时间；前端按`Asia/Shanghai`解释无时区时间 |
| 会话 | 后端内存 Token，8小时有效，重启后需重新登录 |

配置中的默认数据库账号和演示账号只适用于本地课程演示，推送到 GitHub 前必须检查并替换或通过环境变量覆盖。

## 3. 已实现功能

### 用户和权限

- 学生和管理员登录。
- 学生注册，服务端强制注册角色为`STUDENT`。
- 退出登录和8小时内存会话。
- 本人姓名修改。
- 服务端根据 Token 确定当前用户，不信任客户端伪造的用户编号。
- 用户响应不返回密码，新注册密码使用 BCrypt 保存，旧明文账号成功登录时迁移。

### 题库和在线编程

- 管理员新增、编辑、删除题目。
- 题目分类、难度、分值、状态和模拟答案片段配置。
- 学生只能看到已发布题目，不能读取标准答案。
- 学生按分类和难度筛选题目。
- Java 文本编辑、运行和提交。
- 模拟结果：空代码为`RE`，匹配答案片段为`AC`，其他为`WA`。
- 提交记录保存提交编号、代码、结果、分数和判题耗时。
- 草稿按用户和题目隔离，并保存在当前浏览器。

### 考试和成绩

- 管理员创建草稿考试、选择已发布题目、发布或关闭考试。
- 学生查看已发布考试、开始答题、刷新恢复、提前交卷。
- 后端保存个人考试状态和个人截止时间。
- 后台定时任务每10秒处理过期答卷。
- 每个学生每道题取有效时间内的最高分，未答题为0分。
- 重复交卷不重复生成最终成绩。
- 学生查看个人成绩、每题得分、错题和代码详情。
- 管理员按学生或考试查询成绩，并查看交卷人次和平均分。

## 4. 数据库基线

当前主要表：

- `oj_user`：用户和角色。
- `question`：题目和模拟答案。
- `exam`：考试定义。
- `exam_question`：考试与题目的关系及顺序。
- `submission`：提交代码和判题结果。
- `exam_attempt`：学生个人考试状态、开始时间和截止时间。
- `exam_result`：每个学生每场考试的最终成绩。

当前已有的约束：

- 考试题目关系唯一约束。
- 同一学生同一考试只能有一条答卷状态。
- 同一学生同一考试只能有一条最终成绩。
- 考试题目和答卷状态具有外键。
- 被考试或提交记录引用的题目由业务逻辑禁止修改和删除。

数据库升级脚本为`database/upgrade-exams.sql`。升级已有项目时应先备份数据库，不能把本地真实数据提交到代码仓库。

## 5. 接口基线

认证接口：

- `POST /api/auth/login`
- `POST /api/auth/register`
- `GET /api/auth/current`
- `PUT /api/auth/profile`
- `POST /api/auth/logout`

题库接口：

- `GET /api/questions`
- `GET /api/questions/{id}`
- `POST /api/questions`
- `PUT /api/questions/{id}`
- `DELETE /api/questions/{id}`

考试接口：

- `GET /api/exams`
- `POST /api/exams`
- `PUT /api/exams/{id}`
- `POST /api/exams/{id}/start`
- `GET /api/exams/{id}/session`
- `POST /api/exams/{id}/submit`
- `POST /api/exams/{id}/close`

提交和成绩接口：

- `POST /api/submissions/run`
- `POST /api/submissions/submit`
- `GET /api/submissions/my`
- `GET /api/submissions/{id}`
- `GET /api/results/my`
- `GET /api/results`
- `GET /api/results/{examId}`
- `GET /api/results/{examId}/detail`

主要权限规则：除登录和注册外需要 Token；题库和考试管理需要管理员；学生只能查看自己的提交和成绩。

## 8. 当前版本边界

当前版本暂不实现：

- 真实代码编译和执行沙箱。
- 多语言编译执行。
- 高并发判题和分布式架构。
- 微服务和 Docker 集群。
- 在线协作。
- 复杂监考和反作弊。
- 独立用户管理后台。
- 自助修改密码。
