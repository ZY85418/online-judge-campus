## 3. 已实现功能

### 用户和权限

- 学生和管理员登录。
- 学生注册，服务端强制注册角色为`STUDENT`。
- 退出登录和8小时内存会话。
- 本人姓名修改。
- 个人信息页展示用户编号、用户名、姓名、角色、状态和注册时间；管理员可分页查询学生并查看学生详情、答卷摘要和最近提交摘要。
- 服务端根据 Token 确定当前用户，不信任客户端伪造的用户编号。
- 用户响应不返回密码，新注册密码使用 BCrypt 保存，旧明文账号成功登录时迁移。

### 题库和在线编程

- 管理员新增、编辑、删除题目。
- 题目分类、难度、分值、状态和模拟答案片段配置；管理员可选填样例输入和输出，学生练习/考试题面展示已有样例。
- 学生只能看到已发布题目，不能读取标准答案。
- 学生题库以列表展示，支持标题/描述搜索、分类和难度组合筛选，每页50条。
- Java 文本编辑、运行和提交。
- 模拟结果：空代码为`RE`，匹配答案片段为`AC`，其他为`WA`。
- 提交记录保存提交编号、代码、结果、分数和判题耗时。
- 管理员可在提交记录页面按学生编号、考试编号、题目编号和结果筛选最近200条提交摘要，并打开单条完整代码；学生仍只能查询本人列表。
- 草稿按用户和题目隔离，并保存在当前浏览器。

### 考试和成绩

- 管理员创建草稿考试、选择已发布题目、发布或关闭考试。
- 管理员分别设置考试开放开始时间、开放结束时间和个人答题时长；学生列表按当前北京时间显示未开放、开放中或已结束。
- 学生进入考试前看到确认提示；取消不发起开始请求，确认后由后端创建/返回答卷并开始个人倒计时；刷新、重新登录可恢复已开始答卷，关闭页面不会暂停计时。
- 后端保存个人考试状态和个人截止时间。
- 后台定时任务每10秒处理过期答卷。
- 每个学生每道题取有效时间内的最高分，未答题为0分。
- 重复交卷不重复生成最终成绩。
- 学生查看个人成绩、每题得分、错题和代码详情。
- 管理员按学生或考试查询成绩，并查看交卷人次和平均分。

## 4. 数据库基线

当前主要表：

- `oj_user`：用户和角色。
- `question`：题目和模拟答案。
- `exam`：考试定义。
- `exam_question`：考试与题目的关系及顺序。
- `submission`：提交代码和判题结果。
- `exam_attempt`：学生个人考试状态、开始时间和截止时间。
- `exam_result`：每个学生每场考试的最终成绩。

当前已有的约束：

- 考试题目关系唯一约束。
- 同一学生同一考试只能有一条答卷状态。
- 同一学生同一考试只能有一条最终成绩。
- 考试题目和答卷状态具有外键。
- 被考试或提交记录引用的题目由业务逻辑禁止修改和删除。

数据库升级脚本包括`database/upgrade-exams.sql`和`database/upgrade-question-samples.sql`。题目样例升级只增加可空字段；升级已有项目时应先备份数据库，不能把本地真实数据提交到代码仓库。

- `POST /api/auth/register`
- `GET /api/auth/current`

- `GET /api/users/students`、`GET /api/users/students/{id}`（管理员学生查询与详情）

题库接口：

- `GET /api/questions`

- `POST /api/questions`
- `PUT /api/questions/{id}`
- `DELETE /api/questions/{id}`

考试接口：

- `GET /api/exams`
- `GET /api/exams/my-status`（本人逐场答卷状态和最终得分）
- `POST /api/exams`
- `PUT /api/exams/{id}`
- `POST /api/exams/{id}/start`
- `GET /api/exams/{id}/session`
- `POST /api/exams/{id}/submit`
- `POST /api/exams/{id}/close`

提交和成绩接口：

- `POST /api/submissions/run`
- `POST /api/submissions/submit`
- `GET /api/submissions/my`
- `GET /api/submissions/admin`（管理员；userId/examId/questionId/result可选；最多200条，不含代码正文）
- `GET /api/submissions/{id}`
- `GET /api/results/my`
- `GET /api/results`
- `GET /api/results/analytics?examId=...`（管理员单场考试学情统计）
- `GET /api/results/{examId}`
- `GET /api/results/{examId}/detail`

主要权限规则：除登录和注册外需要 Token；题库和考试管理需要管理员；学生只能查看自己的提交和成绩。
