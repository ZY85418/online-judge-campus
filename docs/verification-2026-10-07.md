# 本轮优化验收记录

日期：2026-10-07。范围：H1-H6、M1-M7、L1-L2清单。沿用Vue 3、Vite、Spring Boot 2.7、Java 8、MyBatis-Plus、MySQL，不执行用户代码。

## 已完成的改动

- H1/H2/H4：考试选题发布、开始、恢复、答题、交卷、关闭和后台到期收卷；新增考试题目、个人答卷和最终成绩表，事务与唯一约束保护重复交卷。
- H3：每个学生每题取有效时间内的最高提交分，未答0分，最终成绩独立保存；旧提交不自动转换为考试成绩。
- H5/H6/M3：校验题目和考试参数；无效更新返回404；被考试或提交引用的题目不可修改删除，考试发布后不可编辑。
- M1/M2：学生只访问已发布题目与考试；管理页面支持题目增删改、考试选题和发布；题目按分类、难度筛选。
- M4/M5：注册与本人姓名修改；表单防重复保存，失败保留输入；提交已成功但记录刷新失败时分别提示。
- M6/M7：提交编号及代码详情、个人成绩与错题、管理员成绩筛选和统计；移动端退出入口与viewport补齐。
- L1/L2：同步设计和接口文档，拆出题库管理、考试管理、成绩组件，补充验收清单与实践材料模板。

## 业务边界与后续材料

- 判题仍是Java字符串模拟匹配，运行不保存；最高分只统计已保存的提交，浏览器草稿不参与自动收卷计分。
- Token仍保存在后端内存，重启需要重新登录；考试状态和成绩存数据库。
- 被引用题目需新建版本；发布后的考试需新建考试或关闭，不支持直接编辑。
- 个人信息第一版只修改姓名；不新增自助改密码、真实判题沙箱或复杂框架。
- 实践调研、个人贡献、成员分工及课堂演示记录需按实际情况填写`docs/practice-records.md`，模板不代表这些工作已经完成。

复测步骤见`docs/acceptance.md`；接口约定见`docs/api.md`。临时浏览器脚本、截图及测试报告位于忽略的`backend/target/`目录，清理构建目录前可自行留存。
